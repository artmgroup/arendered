# ARENDERED design system

## 2026-10-08 continuous mobile reading gesture

Project gestures have one owner across the reel and its continuation archive. A vertical swipe advances the horizontal reel first; only the distance remaining after the last credits reach the left edge moves the document down. Reverse gestures retrace that same path. Both horizontal and vertical swipes lock their dominant axis after 4px to avoid direction jitter. Fingers track content directly, without a delayed tween.

On release, the recent gesture velocity continues along the same reading path with exponential deceleration (280ms time constant, maximum 3px/ms, stop below .02px/ms). Velocity is sampled over the most recent 80ms; holding still for 80ms before release suppresses inertia. A fresh touch, menu, route, focus change or viewport resize interrupts movement immediately. Reduced motion preserves direct gestures and omits release inertia. Pinch zoom and player controls remain available.

Scrollable copy consumes vertical movement first; any remaining distance passes to the reel during that same gesture. The same rule applies during deceleration, so long descriptions stay readable without a second swipe at their boundary. Do not restart momentum or reset position when changing from horizontal to vertical travel.

Mechanism references: [beui scroll-animation](https://beui.dev/r/scroll-animation/raw) for interruptible scroll ownership and reduced-motion handling; [StyleGallery reel](https://github.com/changeroa/StyleGallery/blob/main/patterns/in-line-grouping/reel.md) for the existing horizontal container. The combined horizontal-to-vertical gesture is a project-specific extension of the existing controller, with no added runtime dependency. This supersedes the earlier immediate-touch-only rule.

## 6. Motion & interaction
On thumbnail activation, the actual lead image moves from the clicked thumbnail's measured viewport rectangle into its top-aligned project position with a1200ms FLIP transform and cubic-bezier(.65,0,.35,1). The right-hand title/media/description dissolve from0 to1 over900ms after150ms. The existing translucent horse loader remains above these animations with its current timing. Hover opacity eases over160ms. Navigation, scrolling, pointer/keyboard input, resizing and reduced motion cancel or bypass entrance motion; cancellation exposes the settled page immediately and never leaves hidden content. Direct project URLs do not invent a thumbnail origin.
Runtime reference: .preview-link opacity transition 50ms; thumbnail text sits vertically centered and left aligned. Kontakt's public index.js converts desktop wheel motion into horizontal content scrolling, shows #next at the end, and uses normal page scroll for thumbnails. Implement the same reading path with a continuous document, avoiding an artificial jump or route replacement at the corner.
At the top of a project, wheel / trackpad input advances the horizontal reel. Once its end is reached, continued downward input scrolls the document into the continuation archive. Reverse input returns to credits, then traverses the reel backwards. Native touch has the same horizontal-then-vertical path; vertical touch drags in the reel also follow the reading path. Arrow keys and PageUp/PageDown/Space provide equivalent navigation without adding persistent reference-absent UI. Escape returns to the archive. Ctrl-wheel remains browser zoom.
HEJIK's public site.js (v20261007-scatter-size-1), inspected2026-10-07, configures Lenis1.3.25 with lerp0.085, wheelMultiplier0.86, smoothWheel true and syncTouch false. Adapt its frame-rate-independent exponential damping (1-exp(-60*lerp*deltaSeconds)) to one combined reading distance: horizontal reel distance followed by vertical document distance. The existing static site needs no additional dependency or duplicate scroll controller. Scroll input accumulates into an interruptible target; the animation loop runs only until settled (0.5px). Wheel and keyboard use this shared path; touch stays immediate, reduced motion bypasses damping, and route changes, focus, resizing and native pointer gestures cancel pending motion. The beui scroll-animation source corroborates Lenis and native touch as the nearest mechanism. No generic slide-in page animation.
Cross-origin player wheel events do not bubble to the parent. Each player has a bounded vertical scroll buffer (10,000px in either direction), while its iframe stays sticky in the same visible 16:9 stage. Native scroll chaining into this buffer is translated through the same forward/reverse gallery path and the buffer recenters immediately. This supports both directions even when the document is at its top. The buffer is an input bridge, not another visible content region. Native player controls remain interactive without an overlay, and ordinary document focus/scroll behavior is unchanged.
The requested loader follows HEJIK's measured translucent route overlay (42% background, 180ms opacity fade, 560ms minimum appearance). ARENDERED uses a 760ms first appearance, 560ms subsequent appearances, and the approved 880ms horse cycle. It waits only for images intersecting the current viewport, settles on image failure, and releases after at most five seconds. Navigation can interrupt an active load. Reduced motion uses a still frame with no minimum hold and a 100ms fade. The overlay does not intercept input; main exposes its loading state through aria-busy.
