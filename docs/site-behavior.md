# 홈페이지 구성과 동작

## 페이지

Home, About, Portfolio, Development, Contact로 구성합니다. 데스크탑은 왼쪽 사이드바, 모바일은 상단 메뉴를 사용합니다. Art 페이지는 제공하지 않습니다.

Home은 Portfolio로 연결되는 대표 영상을 표시합니다. Portfolio는 영상 12개와 사진 프로젝트 7개를 소개합니다. 영상 미리보기를 누르면 플레이어가 열리고, 사진은 갤러리에서 넘겨 볼 수 있습니다. Development는 3D 공간과 생성형 그래픽 작업을 제공합니다.

Contact는 ARENDERED의 디렉터, 이메일, 전화번호와 공식 인스타그램만 표시합니다.

## 언어와 테마

한국어, 영어, 일본어를 선택할 수 있고, 선택한 언어와 테마는 브라우저에 저장합니다. 기본 테마는 라이트입니다. `styles/site.css`의 공통 변수가 배경, 글씨, 사이드바와 메뉴 색상을 관리합니다.

## 스크롤과 접근성

모바일은 브라우저 기본 세로 스크롤을 사용합니다. 마우스를 사용하는 데스크탑에서만 부드러운 스크롤 효과를 적용합니다. 동작 줄이기 설정을 존중하고 링크, 메뉴와 갤러리는 키보드로 조작할 수 있습니다.

3D 공간 데이터는 해당 페이지에 들어갈 때 로드합니다. 외부 라이브러리는 `assets/vendor/`에 보관하고 필요한 라이선스를 함께 배포합니다.
