# 홈페이지 구성과 동작

## 페이지

Home, About, Works, Contact로 구성합니다. 데스크탑은 왼쪽 사이드바, 모바일은 상단 메뉴를 사용합니다. Art와 Development 페이지는 제공하지 않습니다.

Home은 테두리 없는 대표 이미지로 Works에 연결합니다. Works는 영상 12개와 사진 프로젝트 7개를 소개합니다. 영상 미리보기를 누르면 플레이어가 열리고, 사진은 갤러리에서 넘겨 볼 수 있습니다.

한국어에서는 Works를 작업으로 표시합니다. 첫 영상과 Home 대표 이미지는 Hyundai Motor Studio Seoul Opening Promotion입니다.

Contact는 디렉터 Heewon Jeong과 Jisu Kong, 이메일과 전화번호를 일반 텍스트로 표시합니다. 전화번호 표기는 +82 010 8807 1697입니다.

## 언어와 테마

한국어와 영어를 선택할 수 있고, 선택한 언어와 테마는 브라우저에 저장합니다. 기본 테마는 라이트입니다. `styles/site.css`의 공통 변수가 배경, 글씨, 사이드바와 메뉴 색상을 관리합니다.

## 스크롤과 접근성

모바일은 브라우저 기본 세로 스크롤을 사용합니다. 마우스를 사용하는 데스크탑에서만 부드러운 스크롤 효과를 적용합니다. 동작 줄이기 설정을 존중하고 링크, 메뉴와 갤러리는 키보드로 조작할 수 있습니다.

외부 라이브러리는 `assets/vendor/`에 보관하고 필요한 라이선스를 함께 배포합니다.
