# 홈페이지 구성과 동작

## 화면

작은 고정 헤더와 프로젝트 사진을 중심으로 구성합니다. 기본 테마는 라이트 모드이며 선택한 테마는 브라우저에 저장합니다. 배경, 글씨, 메뉴 색상은 `styles/site.css`의 공통 색상 변수로 관리합니다.

메인 화면의 순서는 Hyundai Motorstudio Seoul, CMF Master Talk, RETRACE, path by, MUSINSA MUJINJANG, KT Y입니다. 썸네일에 마우스를 올리면 프로젝트 이름과 정보가 나타납니다. INDEX는 Selected Works 목록을 열고, 동그라미 i 버튼은 About으로 이동합니다.

## 프로젝트 페이지

사진과 영상은 가로로 이어집니다. 설명은 별도의 읽기 영역에 배치하고 마지막 영역에 `client`, `role`, `assets`, `year`와 제작 크레딧을 한 번 표시합니다. 역할 이름의 각 단어 묶음은 중간에서 끊지 않습니다. 제작 크레딧의 이름은 위쪽 정보의 값과 같은 열에 정렬합니다.

가로 이동이 끝나면 아래의 프로젝트 목록으로 이어집니다. 모바일에서는 손가락 움직임을 직접 반영하고 끝에 닿았을 때 client와 role 줄 높이만큼 짧게 내려갑니다. 사진이나 갤러리 높이를 줄이거나 크레딧을 별도로 위로 이동시키지 않습니다. 설명이 길면 해당 영역에서 전체 내용을 읽을 수 있습니다. 데스크탑에서는 휠 입력을 부드럽게 반영합니다.

## 접근성과 미디어

링크와 버튼에는 접근 가능한 이름을 제공하고 키보드 이동과 Escape 닫기를 지원합니다. 동작 줄이기를 설정한 브라우저에서는 애니메이션을 생략하거나 줄입니다. 영상의 기본 재생 기능은 영상 플레이어가 처리합니다.

사진의 전체 파일과 화면 크기별 썸네일은 각 프로젝트 폴더에서 관리합니다. 본문 이미지의 선택 번호는 프로젝트 데이터에서 유지합니다. 파일 이동 시에는 이미지 경로, 썸네일 후보 경로, 글꼴 경로와 아이콘 경로를 함께 갱신합니다.
